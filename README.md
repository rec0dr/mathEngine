# Math Engine

A Python-based graphing engine built with Pygame.

## Features

 - Graph rendering
 - Camera movement and zoom
 - Mathematical expression objects
 - Screen UI
 - Customizable (and default) styles for each object
 - Function analyzer

## Technologies

 - Python
 - Pygame
 - Git

# Getting Started

Playing around with Math Engine is a rather simple task to begin. There are no extreme prerequisites needed.
